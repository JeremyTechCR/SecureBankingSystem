# Reglas permanentes del repositorio

- Utilizar nombres de clases, métodos y variables en inglés.
- Escribir la documentación y las explicaciones del proyecto en español.
- No guardar secretos, contraseñas, cadenas de conexión ni claves criptográficas en Git.
- Usar `decimal`, nunca `double`, para valores monetarios.
- Utilizar UTC para las fechas del sistema.
- Usar `CancellationToken` en las operaciones asíncronas.
- Mantener las reglas del negocio fuera de controladores y endpoints.
- Respetar estrictamente las dependencias de Clean Architecture.
- Agregar o actualizar pruebas con cada comportamiento.
- No introducir paquetes sin explicar su necesidad.
- No ejecutar commits ni push salvo petición explícita.
- No afirmar que una validación pasó si no fue ejecutada correctamente.
